# Definition of Done (DoD)

งานจะถือว่า "Done" และเสร็จสมบูรณ์ในแต่ละ Sprint เมื่อผ่านเกณฑ์ทั้งหมดดังนี้:
1. **Acceptance Criteria Pass:** โค้ดผ่านเงื่อนไข Acceptance Criteria ทุกข้อที่ระบุไว้ใน Issue
2. **Code Quality:** โค้ดผ่านการจัด Format และไม่มี Syntax Error
3. **Branch & PR Workflow:** โค้ดถูกส่งผ่าน Feature Branch และผ่านการ Review & Approve จากสมาชิกทีมอย่างน้อย 1 คน
4. **No Direct Main Push:** ไม่มีการ Push โค้ดเข้าสู่ Branch `main` โดยตรง
5. **Cross-Browser Verification:** หน้าจอเว็บทำงานได้ถูกต้องบน Google Chrome และ Safari
