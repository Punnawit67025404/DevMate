🤖 AI Usage
ทีมใช้ Generative AI เป็นเครื่องมือช่วยสนับสนุนการวิเคราะห์ การจัดทำเอกสาร และการตรวจสอบแนวทางในการพัฒนาโปรเจกต์ โดยมีการใช้งานดังนี้
🔍 1. Technology Research
ใช้ AI ช่วย เปรียบเทียบข้อดี ข้อจำกัด และความเหมาะสม ของเทคโนโลยีสำหรับการพัฒนา Prototype เพื่อช่วยให้ทีมเห็นทางเลือกก่อนตัดสินใจ
📝 2. ADR Drafting
ใช้ AI ช่วย จัดโครงสร้างและร่างเนื้อหา ในรูปแบบ Context, Decision และ Consequences ให้เป็นไปตามแนวทางของ Architecture Decision Record (ADR)
🛠️ 3. Technical Analysis
ใช้ AI ช่วยวิเคราะห์ประเด็นทางเทคนิค เช่น
🔐 Row Level Security (RLS)
🔗 Vendor Lock-in
⏳ Free Tier Limitations
เพื่อช่วยให้ทีมสามารถระบุและประเมิน ความเสี่ยงที่อาจเกิดขึ้น จากการเลือกใช้เทคโนโลยี
✅ 4. Decision Validation
ทีมเป็นผู้ ตรวจสอบข้อมูลและพิจารณาความเหมาะสม กับข้อกำหนดของโปรเจกต์ก่อนนำไปใช้จริง โดยการตัดสินใจเลือก Tech Stack เป็นความรับผิดชอบของสมาชิกในทีม
