# ADR-001: การตัดสินใจเลือกเทคโนโลยีหลัก (Selection of Core Technology Stack)

**Status:** ยอมรับแล้ว (Accepted)

**Context (บริบท):**
โปรเจกต์ของเราชื่อว่า "DevMate" ซึ่งเป็นแพลตฟอร์มสำหรับนิสิตมหาวิทยาลัยเพื่อค้นหาและจับคู่ (Match) เพื่อนร่วมทีมทำโปรเจกต์ตามทักษะความสามารถ (Skills) ทีมของเรามีความจำเป็นที่จะต้องสร้างต้นแบบ (Prototype) และทดสอบระบบอย่างรวดเร็วภายใน 1 ภาคการศึกษา เราจึงต้องการเครื่องมือที่ทันสมัย รองรับการจัดการข้อมูลผู้ใช้และระบบ Authentication ได้ง่าย และใช้เวลาในการตั้งค่า Backend ให้น้อยที่สุด เพื่อให้ทีมโฟกัสกับการทำระบบ Matching ได้เต็มที่

**Decision (การตัดสินใจ):**
เราได้ตัดสินใจเลือกใช้เทคโนโลยีหลักสำหรับระบบ (Tech Stack) ดังต่อไปนี้:
- **Frontend / Full-stack Framework:** Next.js (พร้อมด้วย Tailwind CSS สำหรับจัดการ UI)
- **Backend & Database:** Supabase (Backend-as-a-Service สำหรับจัดการ Database, API และ Authentication)
- **Deployment:** Vercel

**Consequences (ผลกระทบที่ตามมาจากการตัดสินใจ):**
*   **Positive (ข้อดี):**
    - **Development Speed:** Supabase ให้บริการฟีเจอร์ Backend สำเร็จรูป ทั้งฐานข้อมูล, ระบบ Authentication, และ API (BaaS) ซึ่งช่วยลดเวลาในการตั้งค่าเซิร์ฟเวอร์จากศูนย์ ทำให้ทีมสามารถดึงและบันทึกข้อมูลผ่าน SDK ได้ทันที และทำระบบจับคู่ทักษะ (Skill Matching) ได้เร็วขึ้น
    - **Seamless Deployment:** Next.js พัฒนาโดย Vercel ทำให้การนำระบบขึ้นใช้งาน (Deploy) ทำได้ง่ายแบบแทบไม่ต้องตั้งค่าใดๆ (Zero-configuration)
    - **Developer Experience:** การใช้ Next.js ร่วมกับ Tailwind CSS ช่วยให้สร้างหน้า UI ที่ทันสมัยและโต้ตอบได้ดี ตอบโจทย์การใช้งานของกลุ่มนิสิต
*   **Negative (ข้อควรระวัง/ข้อจำกัด):**
    - **Learning Curve:** การตั้งค่าความปลอดภัยระดับข้อมูล (Row Level Security - RLS) ของ Supabase เพื่อป้องกันไม่ให้ผู้ใช้แก้ไขโปรไฟล์ของคนอื่น อาจต้องใช้เวลาศึกษาเพิ่มเติมสำหรับสมาชิกในทีม
    - **Vendor Lock-in Risk:** การพึ่งพาฟีเจอร์เฉพาะของ Vercel และ Supabase มากเกินไป อาจทำให้การย้ายระบบไปยัง Cloud Provider อื่นๆ ในอนาคตทำได้ยาก
    - **Free Tier Limitations:** ข้อจำกัดของ Supabase รุ่นฟรี (เช่น โปรเจกต์จะหยุดทำงานหากไม่มีการใช้งานระยะหนึ่ง) อาจทำให้เกิดความล่าช้าเล็กน้อย ("Cold starts") ระหว่างที่อาจารย์หรือเพื่อนทดลองเข้าใช้งานระบบ
