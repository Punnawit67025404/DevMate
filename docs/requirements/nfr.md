📋 Non-Functional Requirements

NFR — ระบบจัดตารางเวรพยาบาล
ข้อกำหนดด้านคุณภาพและประสิทธิภาพของระบบที่สามารถตรวจสอบและวัดผลได้

⚡ 1. Performance

เป้าหมาย: ระบบตอบสนองได้รวดเร็ว

⏱️ Response Time: ไม่เกิน 2 วินาที

📊 ครอบคลุมอย่างน้อย 95% ของคำขอทั้งหมด

📁 2. File Upload

เป้าหมาย: รองรับการอัปโหลดไฟล์สำหรับการใช้งานระบบ

📄 ขนาดไฟล์สูงสุด: 20 MB ต่อไฟล์

📦 รองรับการอัปโหลดพร้อมกันอย่างน้อย 10 ไฟล์

👥 3. Concurrent Users

เป้าหมาย: รองรับผู้ใช้งานหลายคนพร้อมกัน

👤 รองรับผู้ใช้งานพร้อมกันอย่างน้อย 500 คน

⏱️ Response Time ต้องไม่เกิน 3 วินาที

🔐 4. Security

เป้าหมาย: ลดความเสี่ยงจากการเข้าสู่ระบบด้วยรหัสผ่านที่ผิดซ้ำ

❌ หากกรอกรหัสผ่านผิดติดต่อกัน 5 ครั้ง

🔒 ระบบต้องระงับการเข้าสู่ระบบเป็นเวลา 15 นาที

💾 5. Backup & Recovery

เป้าหมาย: ป้องกันข้อมูลสูญหายและรองรับการกู้คืนข้อมูล

🔄 สำรองข้อมูลอย่างน้อย 1 ครั้งต่อวัน

📅 เก็บข้อมูลสำรองย้อนหลังอย่างน้อย 7 วัน
