## Story US-01: สร้างและโพสต์โปรเจกต์

**As a** Project Creator
**I want** กรอกข้อมูลและโพสต์โปรเจกต์พร้อมระบุทักษะที่ต้องการได้ภายใน 3 ขั้นตอน
**So that** ฉันสามารถประหยัดเวลาและเริ่มหาเพื่อนร่วมทีมได้อย่างรวดเร็ว

**Acceptance Criteria**

* [ ] AC1: ผู้ใช้สามารถกรอกชื่อโปรเจกต์ รายละเอียด ระยะเวลา และทักษะที่ต้องการได้
* [ ] AC2: ผู้ใช้สามารถสร้างและเผยแพร่โปรเจกต์ได้ภายใน 3 ขั้นตอน
* [ ] AC3: ระยะเวลาตั้งแต่กด "Create Project" จนถึง "Publish" ต้องไม่เกิน 5 นาที
* [ ] AC4: หากข้อมูลที่จำเป็นไม่ครบ ระบบต้องแจ้งเตือนและไม่อนุญาตให้เผยแพร่
* [ ] AC5: เมื่อเผยแพร่สำเร็จ ระบบต้องแสดงสถานะว่าโปรเจกต์ถูกเผยแพร่แล้ว

**Priority:** Must

**Estimate:** S

**INVEST:** Independent, Negotiable, Valuable, Estimable, Small และ Testable โดยสามารถทดสอบได้จากจำนวนขั้นตอนและเวลาที่ใช้ตั้งแต่ Create Project จนถึง Publish

## Story US-02: ระบุทักษะที่ต้องการสำหรับโปรเจกต์

**As a** Project Creator
**I want** ระบุทักษะและเทคโนโลยีที่ต้องการสำหรับสมาชิกทีม
**So that** ระบบสามารถนำข้อมูลไปใช้ค้นหาและจับคู่ผู้สมัครที่เหมาะสมกับโปรเจกต์ได้

**Acceptance Criteria**

* [ ] AC1: ผู้ใช้สามารถเลือกหรือระบุทักษะที่ต้องการ เช่น Node.js, Python, React และ UI/UX ได้
* [ ] AC2: ผู้ใช้สามารถระบุทักษะได้มากกว่า 1 รายการ
* [ ] AC3: ระบบต้องแสดงทักษะที่ผู้ใช้เลือกก่อนเผยแพร่โปรเจกต์
* [ ] AC4: หากไม่ระบุทักษะที่จำเป็น ระบบต้องแจ้งเตือนก่อนเผยแพร่
* [ ] AC5: ทักษะที่บันทึกไว้ต้องแสดงในรายละเอียดของโปรเจกต์

**Priority:** Must

**Estimate:** S

**INVEST:** Independent จากระบบจับคู่ สามารถพัฒนาและทดสอบการบันทึกทักษะได้แยกจากฟังก์ชันอื่น

## Story US-03: ค้นหาผู้สมัครด้วย Smart Skill-Match

**As a** Project Creator
**I want** ให้ระบบจับคู่ผู้สมัครจากทักษะที่โปรเจกต์ต้องการโดยอัตโนมัติ
**So that** ฉันสามารถค้นหาผู้สมัครที่เหมาะสมได้โดยไม่ต้องคัดกรองด้วยตนเองจากหลายแพลตฟอร์ม

**Acceptance Criteria**

* [ ] AC1: ระบบต้องนำทักษะที่โปรเจกต์ต้องการไปเปรียบเทียบกับทักษะของผู้สมัคร
* [ ] AC2: ระบบต้องแสดงรายชื่อผู้สมัครที่มีทักษะตรงกับความต้องการ
* [ ] AC3: ระบบต้องแสดง Match Score ของผู้สมัครแต่ละคน
* [ ] AC4: ความแม่นยำของการจับคู่ต้องไม่น้อยกว่า 80% ตามเกณฑ์ที่ทีมกำหนด
* [ ] AC5: หากไม่พบผู้สมัครที่ตรงกับเงื่อนไข ระบบต้องแจ้งให้ผู้ใช้ทราบ

**Priority:** Must

**Estimate:** M

**INVEST:** แยกจาก Verified Portfolio ได้ และสามารถทดสอบด้วยชุดข้อมูลทักษะที่กำหนดไว้ล่วงหน้า

## Story US-04: ตรวจสอบ Portfolio ของผู้สมัคร

**As a** Project Creator
**I want** ดูผลงานของผู้สมัครผ่าน GitHub หรือ Behance ภายในระบบ
**So that** ฉันสามารถตรวจสอบความสามารถจากผลงานจริงก่อนตัดสินใจรับเข้าทีม

**Acceptance Criteria**

* [ ] AC1: ระบบต้องอนุญาตให้ผู้สมัครเชื่อมต่อ GitHub หรือ Behance
* [ ] AC2: ระบบต้องแสดงลิงก์ Portfolio ที่เชื่อมต่อไว้ในโปรไฟล์
* [ ] AC3: เมื่อเชื่อมต่อสำเร็จ ระบบต้องแสดงข้อมูลผลงานที่สามารถดึงได้
* [ ] AC4: หากไม่สามารถเชื่อมต่อ Portfolio ได้ ระบบต้องแสดงข้อความแจ้งเตือน
* [ ] AC5: ระบบต้องไม่แสดงข้อมูล Portfolio ที่ไม่มีอยู่จริง

**Priority:** Should

**Estimate:** M

**INVEST:** แยกออกจาก Smart Skill-Match เพื่อให้สามารถพัฒนาและทดสอบการเชื่อมต่อ Portfolio ได้อย่างอิสระ

## Story US-05: ค้นหาโปรเจกต์ตามทักษะ

**As a** Skill Provider
**I want** ค้นหาโปรเจกต์โดยเลือกทักษะที่ฉันมี เช่น React, Vue.js และ UI Design
**So that** ฉันสามารถค้นหาโปรเจกต์ที่เหมาะสมกับความสามารถของฉันได้อย่างรวดเร็ว

**Acceptance Criteria**

* [ ] AC1: ผู้ใช้สามารถเลือกทักษะที่ต้องการค้นหาได้
* [ ] AC2: ระบบต้องแสดงโปรเจกต์ที่มีความต้องการตรงกับทักษะที่เลือก
* [ ] AC3: ระบบต้องแสดง Match Score ของโปรเจกต์ที่ค้นพบ
* [ ] AC4: ระบบต้องแสดงผลการค้นหาภายใน 3 นาทีตามเกณฑ์ที่กำหนด
* [ ] AC5: หากไม่พบโปรเจกต์ที่ตรงกับทักษะ ระบบต้องแจ้งให้ผู้ใช้ทราบ

**Priority:** Must

**Estimate:** M

**INVEST:** Independent จากการสมัครเข้าทีม และสามารถทดสอบได้จากทักษะที่ใช้ค้นหาและผลลัพธ์ที่ระบบแสดง

## Story US-06: ตรวจสอบรายละเอียดโปรเจกต์ก่อนสมัคร

**I want** ดูรายละเอียดโปรเจกต์ เช่น Tech Stack, Timeline และ Milestones ก่อนสมัคร
**So that** ฉันสามารถตัดสินใจได้ว่าโปรเจกต์ตรงกับความสนใจและความสามารถของฉันหรือไม่

**Acceptance Criteria**

* [ ] AC1: ระบบต้องแสดงรายละเอียดของโปรเจกต์ที่ผู้สร้างกรอกไว้
* [ ] AC2: ระบบต้องแสดง Tech Stack ที่ใช้ในโปรเจกต์
* [ ] AC3: ระบบต้องแสดง Timeline และ Milestones หากผู้สร้างระบุข้อมูลไว้
* [ ] AC4: ผู้ใช้สามารถดูรายละเอียดโปรเจกต์ได้โดยไม่ต้องสมัครก่อน
* [ ] AC5: หากข้อมูลบางส่วนไม่มี ระบบต้องแสดงสถานะว่าไม่มีข้อมูลแทนการแสดงข้อมูลผิด

**Priority:** Must

**Estimate:** S

**INVEST:** Independent จากระบบสมัครเข้าทีม และสามารถทดสอบได้จากการตรวจสอบข้อมูลที่แสดงในหน้า Project Details

## Story US-07: สมัครเข้าร่วมโปรเจกต์พร้อม Portfolio

**As a** Skill Provider
**I want** สมัครเข้าร่วมโปรเจกต์พร้อมข้อความแนะนำตัวและ Portfolio Link
**So that** Project Creator สามารถพิจารณาความเหมาะสมของฉันได้ง่ายขึ้น

**Acceptance Criteria**

* [ ] AC1: ผู้ใช้สามารถกดปุ่ม Apply จากหน้าโปรเจกต์ได้
* [ ] AC2: ระบบสามารถสร้างข้อความแนะนำตัวจากข้อมูลของผู้ใช้ได้
* [ ] AC3: ผู้ใช้สามารถตรวจสอบและแก้ไขข้อความก่อนส่งใบสมัคร
* [ ] AC4: ผู้ใช้สามารถแนบ Portfolio Link ก่อนส่งใบสมัคร
* [ ] AC5: เมื่อสมัครสำเร็จ ระบบต้องแสดงสถานะใบสมัครให้ผู้ใช้ทราบ
* [ ] AC6: หากโปรเจกต์ปิดรับสมัครแล้ว ระบบต้องไม่อนุญาตให้ส่งใบสมัคร

**Priority:** Must

**Estimate:** M

**INVEST:** Independent จากระบบค้นหาโปรเจกต์ และสามารถทดสอบได้จากขั้นตอนการส่งใบสมัครและสถานะหลังสมัคร

## Story US-08: ติดตามสถานะการสมัครเข้าทีม

**As a** Skill Provider
**I want** ตรวจสอบสถานะใบสมัครของฉัน
**So that** ฉันสามารถทราบว่าผู้สร้างโปรเจกต์ได้รับและพิจารณาใบสมัครของฉันแล้วหรือยัง

**Acceptance Criteria**

* [ ] AC1: ระบบต้องแสดงรายการโปรเจกต์ที่ผู้ใช้สมัครไว้
* [ ] AC2: ระบบต้องแสดงสถานะของใบสมัคร เช่น Pending, Accepted หรือ Rejected
* [ ] AC3: ระบบต้องอัปเดตสถานะเมื่อ Project Creator เปลี่ยนสถานะใบสมัคร
* [ ] AC4: เมื่อใบสมัครได้รับการตอบรับ ระบบต้องแสดงสถานะ Accepted อย่างชัดเจน
* [ ] AC5: ผู้ใช้สามารถตรวจสอบสถานะใบสมัครได้จากหน้าโปรไฟล์หรือหน้า Applications

**Priority:** Should

**Estimate:** S

**INVEST:** Independent จากระบบค้นหาและระบบสมัคร สามารถพัฒนาและทดสอบโดยใช้สถานะใบสมัครที่กำหนดไว้
