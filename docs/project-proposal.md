# Project Proposal

### 1. Theme
Tools for Modern Learners (เหตุผลที่เลือก: ต้องการแก้ปัญหาความกระจัดกระจายในการหาเพื่อนร่วมทีมทำโปรเจกต์ของนิสิต และสร้างพื้นที่จับคู่ทักษะที่ตรงกับความต้องการจริง)

### 2. Project Name
DevMate

### 3. Persona
- **กิตติพัฒน์ (Project Creator):** นิสิตผู้มีไอเดียพัฒนาโปรเจกต์แต่ขาดทีมที่มีทักษะเฉพาะทาง ต้องการระบบจับคู่และคัดกรองสมาชิกตามสกิลที่ตรงจุดอย่างรวดเร็ว
- **สิรภัทร (Skill Provider):** นิสิตสาย Frontend/UI ที่ต้องการหาโปรเจกต์คุณภาพเพื่อสะสมผลงานลงพอร์ตโฟลิโอ และต้องการความชัดเจนของขอบเขตงานก่อนสมัคร

### 4. Value Proposition
แพลตฟอร์มจับคู่ทีมทำโปรเจกต์สำหรับนิสิต ที่มีระบบ Smart Skill-Match และ Verified Portfolio ช่วยลดเวลาการคัดกรองคน เพิ่มความมั่นใจในทักษะจริง และลดการสื่อสารที่กระจัดกระจาย

### 5. MoSCoW Priorities
- **Must Have:** ระบบสร้างและโพสต์โปรเจกต์ (ระบุทักษะที่ต้องการ), ระบบโปรไฟล์และแสดงลิงก์พอร์ตโฟลิโอ (GitHub/Behance), ระบบค้นหาและจับคู่ทักษะ (Skill Match), ระบบส่งคำเชิญและตอบรับเข้าทีม
- **Should Have:** ระบบคำนวณ Match Score ความเข้ากันได้ของสกิล, แดชบอร์ดสรุปภาพรวมและไทม์ไลน์ของโปรเจกต์
- **Could Have:** ระบบ Integrated Chat และปุ่มนัดหมายประชุมออนไลน์ (Zoom/Google Meet)
- **Won’t Have (This term):** ระบบคัดกรองอัตโนมัติด้วย AI Vector Similarity ขั้นสูงเต็มรูปแบบ

### 6. Risks & Assumptions
- **Assumption:** นิสิตผู้สมัครยินดีเปิดเผยและเชื่อมต่อลิงก์พอร์ตโฟลิโอสาธารณะ เช่น GitHub หรือ Behance
- **Risk:** ปัญหา Rate Limit หรือความเปลี่ยนแปลงของ External API ในการดึงข้อมูลสถิติผลงานภายนอก
