# Sprint 1 Prototype: DevMate - Nonpawit_login

## 1. User Story ที่อ้างอิง
> **User Story (Must Priority):** 
> "ในฐานะนิสิต/นักศึกษา ฉันต้องการลงทะเบียนเข้าใช้งานด้วยอีเมลมหาวิทยาลัยและยืนยันตัวตนด้วยรหัส OTP ได้ เพื่อให้มั่นใจได้ว่าเป็นผู้ใช้งานจริงภายในมหาวิทยาลัยและเข้าใช้งานระบบจับคู่หาเพื่อนร่วมทีมได้อย่างปลอดภัย"

---

## 2. การตัดสินใจเลือก: Prototype (Throwaway Prototype)

ทีมเลือกพัฒนาเป็น **Prototype (แบบทิ้งได้)** สำหรับ Sprint 1

**เหตุผลในการตัดสินใจ:**
* **เน้นเรียนรู้ UX/UI และ Verification Flow:** ต้องการทดสอบ User Flow การลงทะเบียนและการป้อนรหัส OTP ผ่าน Pop-up Modal ว่าผู้ใช้งานเข้าใจลำดับขั้นตอนและป้อนข้อมูลได้สะดวกหรือไม่
* **ยังไม่เชื่อมต่อระบบ Authentication จริง:** โค้ด HTML/CSS/JS ชุดนี้เขียนขึ้นด้วย Plain Vanilla เพื่อความรวดเร็วในการทดสอบแนวคิด (Proof of Concept) และตั้งใจจะทิ้งเพื่อนำไปเขียนใหม่ด้วย Production Framework, Auth Service และ REST API ใน Sprint 2

---

## 3. สิ่งที่ทำได้ (Completed Features)

1. **ระบบตรวจสอบเงื่อนไขข้อมูลอินพุต (Client-side Form Validation):**
   * ตรวจสอบโดเมนอีเมลนิสิตแบบเจาะจง (`@university.ac.th`) พร้อมแสดงข้อความเตือน (Hint) ทันทีเมื่อกรอกผิด
   * ตรวจสอบความยาวรหัสผ่าน (อย่างน้อย 8 ตัวอักษร) และตรวจสอบความถูกต้องของการยืนยันรหัสผ่าน (Password Matching)
2. **ระบบการโต้ตอบของ OTP Modal (Interactive OTP Modal):**
   * ควบคุมการเลื่อนโฟกัสอัตโนมัติ (Auto-focus) เมื่อผู้ใช้พิมพ์รหัส OTP ทีละตัวในช่อง 6 หลัก และรองรับการกด Backspace เพื่อถอยกลับ
   * ระบบเปิด-ปิด Modal เมื่อส่งฟอร์มผ่าน และการจำลองกดส่งรหัสใหม่ (Resend OTP)

---

## 4. สิ่งที่ตั้งใจ "ไม่ได้ทำ" ใน Sprint นี้ (Out of Scope / Deliberately Omitted)

* **Real Email & SMTP Server:** ยังไม่มีการส่งอีเมลที่มีรหัส OTP ไปยังตู้ผู้รับจริง (เป็นการจำลอง Modal Popup ให้ผู้ใช้ลองกรอกเท่านั้น)
* **Backend Validation & Security:** ยังไม่มีการนำรหัสผ่านไปผ่านกระบวนการ Hashing (เช่น bcrypt) หรือตรวจสอบความปลอดภัยฝั่ง Server
* **Database & Account Storage:** ไม่มีการบันทึกข้อมูลการลงทะเบียนลงฐานข้อมูลจริง
* **Session & Token Management:** เมื่อกรอก OTP ผ่านแล้ว ยังไม่มีการสร้าง JWT หรือ Session ในการรักษาสถานะการล็อกอิน
