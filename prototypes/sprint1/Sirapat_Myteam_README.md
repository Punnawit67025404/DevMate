# Sprint 1 Prototype: DevMate - MyTeam

## 1. User Story ที่อ้างอิง
> **User Story (Must Priority):** 
> "ในฐานะสมาชิกในทีม/หัวหน้าโครงการ ฉันต้องการเวิร์กสเปซสำหรับติดตามงานเร่งด่วน สื่อสารผ่านห้องแชตกลุ่ม และดูภาพรวมแผนงานในทีมได้ เพื่อให้การทำงานร่วมกันเป็นไปอย่างมีประสิทธิภาพและไม่ตกหล่น"

---

## 2. การตัดสินใจเลือก: Prototype (Throwaway Prototype)

ทีมเลือกพัฒนาเป็น **Prototype (แบบทิ้งได้)** สำหรับ Sprint 1

**เหตุผลในการตัดสินใจ:**
* **เน้นทดสอบ UX/UI และ Layout เวิร์กสเปซ:** ต้องการทดลองจัด Layout แบบ 3 คอลัมน์ (เมนูและตารางนัดหมาย / ห้องแชตหลัก / งานเร่งด่วนและประกาศรับสมัคร) เพื่อดูความสะดวกในการสลับมุมมองของผู้ใช้
* **ยังไม่ลงโครงสร้าง real-time architecture:** โค้ด HTML/CSS ชุดนี้เขียนขึ้นด้วย Plain Vanilla เพื่อทดสอบการวางองค์ประกอบอินเทอร์เฟซ (Proof of Concept) และตั้งใจจะทิ้งเพื่อเขียนใหม่ด้วย Production Framework, WebSocket และ REST API ใน Sprint 2

---

## 3. สิ่งที่ทำได้ (Completed Features)

1. **โครงสร้างเวิร์กสเปซหลัก (Workspace Layout):**
   * แถบ Sidebar ซ้ายแสดงเมนูหลัก (ห้องแชต, แผนงานย่อย, คลังไฟล์, ปฏิทิน) พร้อมกล่องแจ้งเตือนการประชุมถัดไป
2. **ระบบจำลองห้องแชตกลุ่ม (Group Chat UI):**
   * การจัดวาง Message Bubble แยกฝั่งผู้ส่ง (ขวา) และผู้รับ (ซ้าย) พร้อมแสดงเวลาและรูปโปรไฟล์
   * การแสดงผลการ์ดไฟล์แนบ (`login-screen.png`) ในกล่องข้อความ
   * ช่องป้อนข้อความ (Chat Input) พร้อมปุ่มแนบไฟล์และปุ่มส่ง
3. **การแสดงสถานะงานเร่งด่วน (Task Status Visualization):**
   * แถบ Sidebar ขวาแสดงรายการงานสัปดาห์นี้ พร้อม Badge สีแยกสถานะชัดเจน (เสร็จสิ้น, กำลังดำเนินการ, รอดำเนินการ)
   * ส่วนแสดงประกาศรับสมัครตำแหน่งผู้ช่วยในทีม (Backend / UI UX)

---

## 4. สิ่งที่ตั้งใจ "ไม่ได้ทำ" ใน Sprint นี้ (Out of Scope / Deliberately Omitted)

* **Real-time Messaging:** ยังไม่มีการต่อเชื่อม Socket.io หรือ WebSocket เมื่อพิมพ์ข้อความแล้วกดส่ง ข้อความยังไม่ถูกเพิ่มเข้าหน้าจอจริง
* **Backend & File Storage:** ปุ่มแนบไฟล์ และปุ่มเข้าประชุมทีมยังไม่สามารถอัปโหลดไฟล์หรือเชื่อมต่อระบบ Video Conference จริงได้
* **Dynamic Task Data:** ข้อมูลงานเร่งด่วนและประกาศรับสมัครเป็น Dummy Data ยังไม่มีการดึงข้อมูลจาก Database
* **Authentication & Role Access:** ยังไม่มีระบบระบุตัวตนจริง (รูปและชื่อผู้ใช้ยังใช้การ Hardcode)

---

## 5. แผนการต่อยอดใน Sprint 2 (Next Steps)

* นำ Feedback โครงสร้างหน้า MyTeam ไปสร้างเป็น React/Vue Components ใน Sprint ถัดไป
* พัฒนาแบบ **Tracer Bullet** โดยเริ่มสร้าง Database Schema สำหรับ Messages, Tasks และตั้งค่า WebSocket สำหรับระบบแชตจริง
* ต่อเชื่อมระบบอัปโหลดไฟล์จริงเข้ากับ Cloud Storage
