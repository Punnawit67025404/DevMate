# Sprint 1 Prototype: Student Profile & Skill Tags Management

## 1. User Story อ้างอิง
> **User Story:** ในฐานะนิสิตทั่วไป ฉันต้องการจัดการหน้าโปรไฟล์และเลือกแท็กทักษะ (เช่น Next.js, Supabase) พร้อมระดับความชำนาญ เพื่อให้ระบบนำไปใช้ประมวลผลจับคู่เข้าทีม *(Priority: Must)*

---

## 2. การจัดประเภท: Prototype (ทิ้งได้)
งานชิ้นนี้ถูกพัฒนาในรูปแบบ **Prototype**

### เหตุผลในการเลือก:
* **ทดสอบ User Flow & Layout:** ต้องการทดลองจัดวาง Layout ระหว่างข้อมูลโปรไฟล์ (Sidebar) คำขอเข้าร่วมทีม (Invites) และส่วนการจัดการทักษะ (Skill Tags & Proficiency Level) ว่าใช้งานง่ายและตรงตามความต้องการหรือไม่
* **ยังไม่ผูกกับ Architecture จริง:** โค้ดชุดนี้เน้นการตอบโจทย์ความเข้าใจของ Interaction ในฝั่ง Client-side โดยเขียนเป็น Single HTML/JS เพื่อให้ทดสอบได้รวดเร็ว และพร้อมที่จะทิ้งหรือปรับเปลี่ยน UI ใหม่เมื่อนำไปพัฒนาจริงด้วย Framework หลักใน Sprint ถัดไป

---

## 3. ขอบเขตสิ่งที่ทำได้ (Implemented Features)
* **การจัดการทักษะและความชำนาญ (Dynamic Skill Management):**
  * เพิ่มทักษะใหม่พร้อมเลือกระดับความชำนาญ (20% – 100%)
  * ตรวจสอบค่าว่าง (Validation) และป้องกันการเพิ่มชื่อทักษะซ้ำ (Duplicate check)
  * แสดงผลระดับความชำนาญในรูปแบบ Progress Bar แบบเรียลไทม์
  * สามารถลบแท็กทักษะออกจากรายการได้ทันที
  * รองรับการกดปุ่ม `Enter` ในช่องกรอกเพื่อเพิ่มทักษะทันที
* **การตอบรับคำขอเข้าร่วมทีม (Team Invites Stub):**
  * แสดงรายการคำขอเข้าร่วมทีมพร้อมปุ่ม "ตอบรับ" และ "ปฏิเสธ"
  * เมื่อกดเลือกรายการจะถูกลบออกจากหน้าจอ พร้อมอัปเดตตัวเลขนับจำนวนคำขอแบบ Dynamic
* **การแสดงผลสถานะว่าง (Empty State):**
  * แสดงข้อความแจ้งเตือนเมื่อไม่มีรายการทักษะหรือไม่มีคำขอเข้าร่วมทีมเหลืออยู่

---

## 4. ขอบเขตสิ่งที่ตั้งใจ "ไม่ได้ทำ" (Deliberately Out of Scope)
เพื่อให้การสร้างต้นแบบเสร็จสิ้นภายในกรอบเวลาจำกัดของ Sprint 1 สิ่งต่อไปนี้จึงยังไม่ได้ทำ:
* **Database & Persistence:** ข้อมูลทักษะและคำขอยังทำงานอยู่บน Memory ในเบราว์เซอร์ หาก Refresh หน้าเว็บ ข้อมูลจะกลับไปเป็นค่าเริ่มต้น (ยังไม่ต่อฐานข้อมูลจริงหรือ LocalStorage)
* **Profile Edit Modal:** ปุ่ม "✎ แก้ไขโปรไฟล์" ยังเป็นเพียง Stub แสดงการแจ้งเตือน alert ยังไม่ได้ทำฟอร์มแก้ไขข้อมูลส่วนตัว
* **Matching Algorithm:** ยังไม่มีระบบนำแท็กทักษะไปคำนวณจับคู่กับโปรเจกต์จริง
* **Authentication:** ยังไม่มีระบบระบุตัวตน (Hardcode ข้อมูลโปรไฟล์สำหรับทดสอบหน้าจอเท่านั้น)
* **Advanced Responsive Styling:** เน้นทดสอบบน Desktop Browser เป็นหลัก

2. เชื่อมต่อระบบจัดการทักษะเข้ากับ Database/API เพื่อบันทึกข้อมูลถาวร
3. พัฒนาระบบแก้ไขข้อมูลโปรไฟล์ (Edit Profile) และอัปโหลดรูปภาพจริง
4. เชื่อมต่อแท็กทักษะเข้ากับระบบค้นหาและจับคู่ทีม (Team Matching Engine)
